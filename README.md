# Practica de Manejo masivo de datos [sensores_industriales]

> Una empresa utiliza sensores para monitorear máquinas en cuatro plantas industriales. Cada sensor registra su temperatura y vibración una vez por minuto. La empresa te proporciona el archivo sensores_industriales.csv, que contiene 100,000 mediciones simuladas. Tu trabajo consiste en analizarlo con Python, documentar los resultados y publicar un proyecto reproducible en GitHub.

---

## DataSet 
- sensores_industriales.csv(4.5 MB)
- Datos sobre sensores, temperaturas y vibraciones.
---

## Objetivo
- Aplicar conocimientos de BIG DATA a este dataset de prueba, donde se puedan procesar +100K de registros
---

## Requisitos 
- Se requiere Python y de ser posible una distribución de Linux
- Dependencias descargadas del archivo Requirements.txt en un entorno
---

## Instalación
Sigue estos pasos para ejecutar el proyecto en tu entorno local:

### 1. Clonar el repositorio
git clone https://github.com/XxRaliugaRdzxX/Bigdata_Industry.git

### 2. Entrar al directorio del proyecto
cd Bigdata_Industry

### 3. Instalar las dependencias
- Primero el entorno con el comando `python -m venv .venv`
- Despues activar el entorno `source .venv/bin/activate`
- Al final descargar las dependecias con `pip install -r requirements.txt`


### 4. Iniciar el proyecto
- Correr el comando del script del análisis con `python analisis.py`
